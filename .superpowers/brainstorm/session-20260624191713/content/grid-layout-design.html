Design Details

A

Accent Strip on Headers

Left border with widget-themed color (green=equity, blue=daily, gold=analytics, red=behavior). Helps visual scanning.

B

Inline Control Bar

Size toggle, drag handle, and visibility button all on the right of the header. No external widgets forcing space.

C

Bottom Toolbar

Fixed bar at bottom of widget area showing "Add Widget" dropdown, layout preset buttons, and reset.
